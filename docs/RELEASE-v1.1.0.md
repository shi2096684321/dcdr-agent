# dcdr-agent v1.1.0

首个正式版本后的能力扩展版。在 v1.0.0 的对话 + 创作 + 工具三大闭环基础上，新增**视频生成（创作模式子模式）**与**联网搜索**能力，并提供统一的语音 / 视频 / 搜索功能配置开关。

## ✨ 核心特性

**创作能力（视频生成）**
- 创作模式新增「视频」子模式，支持文生视频任务提交
- 视频生成异步执行，前端轮询状态并展示进度（PENDING → RUNNING → SUCCEEDED / FAILED）
- 生成完成后可预览、下载、复现（参数回填），记录写入 `generations` 表，刷新不丢失

**联网搜索**
- 对话 / 创作场景下可开启「🌐 联网」，模型通过 Function Calling 调用 `web_search` 工具获取实时信息
- 回复下方展示引用来源卡片，可跳转原网页，序号与正文标注对应
- 相同 query 在本轮对话内对重复 `web_search` 调用做去重拦截（避免模型重复发起相同查询）

**功能配置开关**
- 语音 / 视频 / 搜索能力均可通过配置独立启用 / 禁用，便于按需开启

**对话能力**（详见 `docs/05-语言对话模块（未来可扩展项）.md`）
- 流式对话、会话管理、记忆管理、工具调用、对话内文生图等设计已存档，待主线稳定后恢复

**创作能力（文生图）**（v1.0.0 已交付）
- 项目化管理、异步任务、批量生成、参数入库与详情回显

**工具调用 / 多模型适配 / 工程化**
- 继承 v1.0.0 的工具注册表与 SPI Provider 抽象

## 📦 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Spring Boot 3.3.5 · Java 17 · Spring Data JPA · H2 / 关系型数据库 |
| 前端 | Vue 3 · Vite · Element Plus · Pinia |
| 协议 | SSE 流式 · REST · Function Calling |

## 🚀 快速开始

```bash
# 后端（Java 17）
mvn spring-boot:run

# 前端
cd frontend
npm install
npm run dev
```

在 `application.yml` 中配置模型 API Key 与功能开关（`agent.features.*`）；联网搜索需配置对应搜索服务 Key。
