## 1. 项目概述

### 1.1 项目背景

随着大语言模型（LLM）技术的成熟，AI Agent（智能体）成为应用开发的新范式。本项目旨在通过 Java 技术栈构建一个**多模态、可扩展、可配置**的 AI Agent 应用，以网页对话为主要交互形式，支持对接多种 AI 模型服务（对话、图片、语音等），并提供工具调用能力。

### 1.2 项目目标

| 目标类型 | 描述 |
|---------|------|
| **业务目标** | 构建一个可独立运行的 AI 智能助手，支持多轮对话、多模态交互、多模型切换 |
| **技术目标** | 体验 Java 应用开发的完整技术栈，掌握 Spring Boot 3 + WebFlux 响应式编程 + 自定义 Provider SPI 抽象 |
| **学习目标** | 理解 Agent 核心原理（路由决策、工具调用、记忆管理），具备扩展新模型/新工具的能力 |

### 1.3 项目范围

#### 包含（In Scope）

> 语言对话相关能力（双模式中的「对话模式」、会话管理、记忆管理、对话内文生图、工具调用、流式对话增强）**当前已冻结，作为未来可扩展项存档**，详见 [`docs/05-语言对话模块（未来可扩展项）.md`](05-语言对话模块（未来可扩展项）.md)。本期主线聚焦**创作模式**。

- ~~双模式 Web 界面：对话模式(线性聊天) + 创作模式(左控右显,参考 Banana)~~（对话模式冻结，见 `05` 文档）
- 多模型对接（OpenAI 兼容系 / 智谱 GLM / 通义千问 / DeepSeek 等，可配置切换）
- 模型类型驱动 UI 模式自动切换（对话模型→对话模式，图片/视频模型→创作模式）（对话模式部分冻结，见 `05` 文档）
- 多模态交互（图片生成、图片理解；文本对话 / 对话内文生图冻结，见 `05` 文档）
- 创作模式后端：项目管理、图片生成异步任务（提交/轮询/历史）、批量生成、线程池状态可视化
- 会话/项目管理（创作模式部分：创建、切换、重命名、删除、历史查看；对话会话部分冻结，见 `05` 文档）

#### 不包含（Out of Scope）

- 用户认证与权限管理（V1.0 单用户模式）
- RAG 知识库检索（留待 V2.0）
- 多 Agent 协作（留待 V2.0）
- 移动端 App
- 付费计费功能
- 语音输入输出（STT/TTS）：V1.0 仅预留需求，未实装
- 视频生成：V1.0 仅预留 `VideoModelProvider` 接口与 UI 入口，未实装具体能力

### 1.4 术语表

| 术语 | 说明 |
|------|------|
| **Agent** | 智能体，能自主决策并调用工具完成任务的 AI 系统 |
| **LLM** | Large Language Model，大语言模型 |
| **Provider** | 模型提供者，封装特定 AI 服务的调用逻辑 |
| **Tool** | 工具，Agent 可调用的外部能力（如天气查询 API） |
| **Memory** | 记忆，管理对话历史和上下文 |
| **SSE** | Server-Sent Events，服务器推送事件，用于流式输出 |
| **多模态** | 支持多种数据类型（文本、图片、语音）的交互能力 |
| **Function Calling** | 函数调用，LLM 自主决定调用哪个函数/工具的机制 |

## 2. 用户角色与使用场景

### 2.1 用户角色

| 角色 | 描述 | 权限 |
|------|------|------|
| **终端用户** | 通过网页与 Agent 交互的普通用户 | 对话、上传图片、切换模型、管理会话 |
| **开发者** | 扩展系统的开发人员 | 配置新模型、开发新工具、修改系统行为 |

### 2.2 核心使用场景

#### 场景 1：多轮文字对话

```
用户：你好，帮我介绍一下你自己
Agent：你好！我是一个 AI 智能助手，可以帮你...
用户：那你能做什么？
Agent：我可以对话、生成图片、识别图片、查询天气...
```

#### 场景 2：图片生成

```
用户：帮我画一只在月光下的猫
Agent：[路由到图片模型] 正在为你生成图片...
       [返回生成的图片]
       这是一只在月光下的猫，你觉得怎么样？
```

#### 场景 3：图片理解

```
用户：[上传一张图片] 这张图片里有什么？
Agent：[路由到多模态对话模型] 
       这张图片显示的是一座山的风景，山顶有积雪...
```

#### 场景 4：工具调用

```
用户：北京今天天气怎么样？
Agent：[调用天气工具] 
       北京今天晴，气温 28°C，湿度 45%...
用户：那帮我算一下 1234 × 5678
Agent：[调用计算器工具]
       1234 × 5678 = 7006652
```

#### 场景 5：模型切换

```
用户：[在界面下拉框切换模型 从 GPT-4o → 智谱GLM]
用户：继续刚才的话题
Agent：[使用新模型继续对话，记忆保持连续]
```

### 5.2 核心接口示例

#### POST /api/chat/stream（流式对话）

**请求体：**
```json
{
  "sessionId": "sess_abc123",
  "message": "你好，介绍一下你自己",
  "model": "openai-chat"
}
```

**SSE 分块类型（type 字段）：**

| type | 字段 | 说明 |
|------|------|------|
| `chunk` | `content` | 正式回复文本增量 |
| `reasoning` | `content` | 推理（CoT）文本增量 |
| `status` | `message` | 状态提示（如"正在生成图片…"） |
| `tool_call` | `tool`, `args` | 模型发起的工具调用 |
| `tool_result` | `tool`, `result` | 工具执行结果 |
| `image` | `imageUrl` | 生成的图片地址 |
| `context_warning` | `message` | 上下文接近上限提醒 |
| `interrupted` | — | 生成被用户中断 |
| `error` | `message` | 错误信息 |
| `done` | `tokenUsage`, `finishReason` | 流式结束 |

**响应（SSE 流示例）：**
```
data: {"type":"chunk","content":"你好"}

data: {"type":"chunk","content":"！我是"}

data: {"type":"chunk","content":"一个AI助手"}

data: {"type":"tool_call","tool":"weather","args":{"city":"北京"}}

data: {"type":"tool_result","tool":"weather","result":"晴天 28°C"}

data: {"type":"done","tokenUsage":{"prompt":50,"completion":30,"total":80},"finishReason":"stop"}
```

#### POST /api/chat/stop（中断生成）

**请求：** `POST /api/chat/stop?sessionId=sess_abc123`
**响应：**
```json
{ "code": 0, "data": true, "message": "ok" }
```

#### POST /api/images/generate（创作模式生成图片）

**请求体：**
```json
{
  "projectId": "proj_001",
  "prompt": "一只在月光下的猫",
  "model": "openai-image",
  "size": "1024x1024",
  "count": 1
}
```

**响应（异步提交，返回生成记录）：**
```json
{ "code": 0, "data": [{ "id": "gen_001", "status": "pending", "imageUrl": null }], "message": "ok" }
```

前端随后通过 `GET /api/generations/{id}` 轮询状态，完成后 `imageUrl` 填充结果地址。
