## 1. 项目概述

### 1.1 项目背景

随着大语言模型（LLM）技术的成熟，AI Agent（智能体）成为应用开发的新范式。本项目旨在通过 Java 技术栈构建一个**多模态、可扩展、可配置**的 AI Agent 应用，以网页对话为主要交互形式，支持对接多种 AI 模型服务（对话、图片、语音等），并提供工具调用能力。

### 1.2 项目目标

| 目标类型 | 描述 |
|---------|------|
| **业务目标** | 构建一个可独立运行的 AI 智能助手，支持多轮对话、多模态交互、多模型切换 |
| **技术目标** | 体验 Java 应用开发的完整技术栈，掌握 Spring Boot 3 + Spring AI + WebFlux 响应式编程 |
| **学习目标** | 理解 Agent 核心原理（路由决策、工具调用、记忆管理），具备扩展新模型/新工具的能力 |

### 1.3 项目范围

#### 包含（In Scope）

- 双模式 Web 界面：对话模式(线性聊天) + 创作模式(左控右显,参考 Banana)
- 多模型对接（OpenAI / 智谱 GLM / 通义千问 / DALL-E / 可灵 等，可配置切换）
- 模型类型驱动 UI 模式自动切换（对话模型→对话模式，图片/视频模型→创作模式）
- 多模态交互（文本对话、图片生成、图片理解、视频生成、语音输入输出）
- 工具调用能力（计算器、天气、时间等内置工具）
- 多轮对话记忆管理
- 会话/项目管理（创建、切换、历史查看）
- 流式输出（打字机效果）

#### 不包含（Out of Scope）

- 用户认证与权限管理（V1.0 单用户模式）
- RAG 知识库检索（留待 V2.0）
- 多 Agent 协作（留待 V2.0）
- 移动端 App
- 付费计费功能

### 1.4 术语表

| 术语 | 说明 |
|------|------|
| **Agent** | 智能体，能自主决策并调用工具完成任务的 AI 系统 |
| **LLM** | Large Language Model，大语言模型 |
| **Provider** | 模型提供者，封装特定 AI 服务的调用逻辑 |
| **Tool** | 工具，Agent 可调用的外部能力（如天气查询 API） |
| **Memory** | 记忆，管理对话历史和上下文 |
| **SSE** | Server-Sent Events，服务器推送事件，用于流式输出 |
| **多模态** | 支持多种数据类型（文本、图片、语音）的交互能力 |
| **Function Calling** | 函数调用，LLM 自主决定调用哪个函数/工具的机制 |

## 2. 用户角色与使用场景

### 2.1 用户角色

| 角色 | 描述 | 权限 |
|------|------|------|
| **终端用户** | 通过网页与 Agent 交互的普通用户 | 对话、上传图片、切换模型、管理会话 |
| **开发者** | 扩展系统的开发人员 | 配置新模型、开发新工具、修改系统行为 |

### 2.2 核心使用场景

#### 场景 1：多轮文字对话

```
用户：你好，帮我介绍一下你自己
Agent：你好！我是一个 AI 智能助手，可以帮你...
用户：那你能做什么？
Agent：我可以对话、生成图片、识别图片、查询天气...
```

#### 场景 2：图片生成

```
用户：帮我画一只在月光下的猫
Agent：[路由到图片模型] 正在为你生成图片...
       [返回生成的图片]
       这是一只在月光下的猫，你觉得怎么样？
```

#### 场景 3：图片理解

```
用户：[上传一张图片] 这张图片里有什么？
Agent：[路由到多模态对话模型] 
       这张图片显示的是一座山的风景，山顶有积雪...
```

#### 场景 4：工具调用

```
用户：北京今天天气怎么样？
Agent：[调用天气工具] 
       北京今天晴，气温 28°C，湿度 45%...
用户：那帮我算一下 1234 × 5678
Agent：[调用计算器工具]
       1234 × 5678 = 7006652
```

#### 场景 5：模型切换

```
用户：[在界面下拉框切换模型 从 GPT-4o → 智谱GLM]
用户：继续刚才的话题
Agent：[使用新模型继续对话，记忆保持连续]
```

## 5. 接口需求

### 5.1 REST API 概览

| 方法 | 路径 | 描述 | 优先级 |
|------|------|------|--------|
| POST | `/api/chat` | 发送消息（同步） | P0 |
| POST | `/api/chat/stream` | 发送消息（流式 SSE） | P0 |
| GET | `/api/sessions` | 获取会话列表 | P0 |
| POST | `/api/sessions` | 创建新会话 | P0 |
| DELETE | `/api/sessions/{id}` | 删除会话 | P1 |
| GET | `/api/sessions/{id}/messages` | 获取会话历史消息 | P0 |
| GET | `/api/models` | 获取可用模型列表 | P0 |
| POST | `/api/images/generate` | 生成图片 | P1 |
| POST | `/api/files/upload` | 上传文件 | P1 |

### 5.2 核心接口示例

#### POST /api/chat/stream（流式对话）

**请求体：**
```json
{
  "sessionId": "sess_abc123",
  "message": "你好，介绍一下你自己",
  "model": "openai-chat",
  "stream": true
}
```

**响应（SSE 流）：**
```
data: {"type":"chunk","content":"你好"}

data: {"type":"chunk","content":"！我是"}

data: {"type":"chunk","content":"一个AI助手"}

data: {"type":"tool_call","tool":"weather","args":{"city":"北京"}}

data: {"type":"tool_result","result":"晴天 28°C"}

data: {"type":"done","tokenUsage":{"prompt":50,"completion":30,"total":80}}
```

## 7. 验收标准

### 7.1 MVP 验收标准（第一阶段）
