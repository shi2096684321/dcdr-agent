## 3. 核心链路

```
对话:  ChatController → AgentOrchestrator.chat()
       → memory.load(全量, UI口径) + memory.loadWindow(LLM滑窗: system+最近N条, 超限发contextWarning)
       → IntentRouter(路由) / AgentDefinition(agentId) / RAG(knowledgeBaseIds)
       → ModelRegistry → CircuitBreakerChatProvider → LangChain4jChatProvider
       → SSE ChatChunk 流式返回 → memory.save + CostTracker.record

RAG:   上传 → DocumentReaderRegistry → RecursiveSplitter(元数据前缀)
       → embedding(text-embedding-v4/1536) → document_chunks(pgvector)
       检索: RetrievalService TopK=5 / KnowledgeSearchTool 由 LLM 决定调用

工作流: WorkflowController → WorkflowEngine
       steps 模式(顺序) / dag 模式(dag_json 优先, Kahn 拓扑并行轮)
       条件节点(llm/expr) → 审批节点(paused 暂停)
       版本快照 → workflow_versions；状态 → workflow_executions
       触发: WebhookController(token) / ScheduledTaskService(cron)
```

## 4. 关键配置（application.yml）

| 配置 | 默认 | 说明 |
|------|------|------|
| `agent.auth.enabled` | true | JWT 认证总开关；false 全放行 |
| `agent.memory.max-messages` | 6 | ⚠ 未实现截断 |
| `agent.rag.retrieval.top-k / min-score` | 5 / 0.3 | RAG 检索 |
| `agent.v3.quota.*` | false | F-39 配额（429 拦截） |
| `agent.v3.tenant.enabled` | false | F-36 多租户（配额型直通；完整 SaaS 化不实施） |
| `agent.v3.plugin.enabled` | false | F-37 插件加载 |
| `agent.v3.rate-limit.enabled` | false | F-40.3 限流 |
| `agent.v3.circuit-breaker.enabled` | false | F-40.4 熔断 |
| `langchain4j` | - | qwen-chat/zhipu-chat/deepseek-chat/qwen-embedding/ollama-chat |

环境变量：`JWT_SECRET`（≥32 字节）。

## 7. 已知缺口 / 注意事项

- 记忆窗口：`agent.memory.max-messages=6` 通过 `ChatMemory.loadWindow()` 生效（system 全保留 + 最近 N 条给 LLM，数据库不删）；超限时流式发 contextWarning、同步路径写 response.contextWarning（2026-08-27 修复，旧版曾直接删库丢历史）
- LangChain4j ResponseHandle.cancel() 为空实现：用户层可中断，但上游流继续消耗 token
- PostgreSQL JPQL 陷阱：`(:p IS NULL OR col=:p)` 对 LocalDateTime 失效 → 用 `COALESCE`；CONCAT 参数需 `CAST(:p AS string)`
- 工具调用结构化输出需 `enable_thinking=false`；流式 thinking 需 `returnThinking(true)`
- SecurityContextWebFilter 非 @Component（避免双重注册）；@PreAuthorize 不可用于同步返回的 Controller
