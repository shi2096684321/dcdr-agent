## 1. 范围界定

### 1.1 属于「语言对话」的能力

| 类别 | 内容 |
|------|------|
| 交互模式 | 对话模式（左侧会话列表 + 右侧线性消息流） |
| 会话管理 | 会话创建 / 切换 / 重命名 / 删除 / 历史消息查看 |
| 记忆管理 | 多轮对话历史存储、上下文窗口控制、上下文长度估算与超长提醒 |
| 对话功能 | 文本对话、流式输出（SSE 打字机）、消息编辑 / 重试 / 截断、生成中断（stop）、推理（CoT）内容单独展示 |
| 模型能力 | 对话模型（chat）调用、对话内文生图（ChatImageService）、图片理解（多模态 Vision） |
| 工具调用 | calculator / time / weather / image_generation 四个内置工具在对话流中的自动调用与结果回显 |
| 路由 | 根据消息内容 / 图片 / 模型类型路由到对话或图片模型的 `ModelRouter` 逻辑 |

### 1.2 不属于「语言对话」（仍属主线交付）

- 创作模式后端：项目管理、图片生成异步任务（提交 / 轮询 / 历史）、批量生成、线程池状态。
- 图片生成（文生图）本身的 Provider、参数入库、详情回显。
- 视频生成（仍属预留接口 / V1.1）。

## 3. 接口设计（存档）

### 3.1 REST 接口列表

| 方法 | 路径 | 描述 | 状态 |
|------|------|------|------|
| GET | `/api/sessions` | 会话列表 | 冻结 |
| POST | `/api/sessions` | 创建会话 | 冻结 |
| GET | `/api/sessions/{id}` | 会话详情 | 冻结 |
| PUT | `/api/sessions/{id}/title` | 重命名会话 | 冻结 |
| DELETE | `/api/sessions/{id}` | 删除会话 | 冻结 |
| GET | `/api/sessions/{id}/messages` | 会话历史消息 | 冻结 |
| DELETE | `/api/sessions/{id}/messages` | 清空会话消息 | 冻结 |
| POST | `/api/chat/stream` | 发送消息（流式 SSE） | 冻结 |
| POST | `/api/chat/image` | 对话内文生图（SSE） | 冻结 |
| POST | `/api/chat/stop` | 中断当前会话生成 | 冻结 |

### 3.2 核心接口示例

#### POST /api/chat/stream（流式对话）

```json
// 请求体
{
  "sessionId": "sess_abc123",
  "message": "你好，介绍一下你自己",
  "model": "openai-chat"
}
```

**SSE 分块类型（type 字段）：**

| type | 字段 | 说明 |
|------|------|------|
| `chunk` | `content` | 正式回复文本增量 |
| `reasoning` | `content` | 推理（CoT）文本增量 |
| `status` | `message` | 状态提示 |
| `tool_call` | `tool`, `args` | 模型发起的工具调用 |
| `tool_result` | `tool`, `result` | 工具执行结果 |
| `image` | `imageUrl` | 生成的图片地址 |
| `context_warning` | `message` | 上下文接近上限提醒 |
| `interrupted` | — | 生成被用户中断 |
| `error` | `message` | 错误信息 |
| `done` | `tokenUsage`, `finishReason` | 流式结束 |

## 4. 架构与组件（存档）

### 4.1 后端类（原设计，冻结）

| 类 | 职责 |
|----|------|
| `AgentOrchestrator` | 对话编排：加载记忆 → 路由模型 → 流式调用 → 保存记忆 |
| `ModelRouter` | 路由决策：指定模型 / 含图走 Vision / 关键词走图片模型 |
| `ChatMemory` / `InMemoryChatMemory` | 对话记忆接口与内存实现 |
| `SessionManager` / `ChatSession` | 会话管理器与会话对象 |
| `ChatController` / `SessionController` | 对话与会话接口 |
| `ChatModelProvider` / `OpenAIChatProvider` / `ZhipuChatProvider` / `QwenChatProvider` | 对话模型 Provider |
| `ChatRequest` / `ChatResponse` / `ChatChunk` | 对话 DTO |
| `MessageDTO` / `SessionDTO` | 会话 / 消息 DTO |
| tools: `CalculatorTool` / `WeatherTool` / `TimeTool` | 内置工具 |

### 4.2 前端组件（原设计，冻结）

| 组件 | 职责 |
|------|------|
| `ChatMode.vue` | 对话模式容器 |
| `Sidebar.vue` / `SessionList.vue` / `SessionItem.vue` | 会话列表侧栏 |
| `ChatArea.vue` / `MessageList.vue` / `MessageItem.vue` | 对话主区域与消息气泡 |

### 4.3 存储表（冻结）

| 表 | 说明 |
|----|------|
| `sessions` | 会话元数据（标题 / 默认模型 / 系统提示词） |
| `messages` | 完整对话历史（角色 / 内容 / 模型 / 工具调用 / token 消耗） |

## 5. 恢复对话能力时的建议步骤

1. **后端**：确认 `AgentOrchestrator` / `ModelRouter` / `ChatController` / 记忆与会话层可编译；若期间主线改动影响 Provider SPI，需同步适配 `ChatModelProvider`。
2. **前端**：在 `App.vue` 恢复对话 / 创作模式切换；对话模式组件随 `ChatMode.vue` 挂载。
3. **配置**：`application.yml` 中对话模型（`agent.models.chat`）启用并补充 API Key。
4. **验收**：对照第 2 节功能需求逐项验证（流式 / 编辑 / 中断 / 工具调用 / 记忆窗口）。
