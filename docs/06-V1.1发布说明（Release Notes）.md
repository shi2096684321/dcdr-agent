## 1. 概述

V1.1 在 V1.0 创作模式主线上，新增**视频生成**与**联网搜索**两项能力，并提供统一的**功能配置开关**（语音 / 视频 / 搜索可独立启用禁用）。

## 2. 新增能力

### 2.1 视频生成（创作模式 · 视频子模式）

- 在创作模式新增「视频」子模式（`CreativeMode.vue` 顶部 Tab 切换）。
- 支持文生视频：选模型（如可视频模型）→ 填提示词 → 提交。
- 后端 `POST /api/videos/generate` 异步提交，`CreativeEngine.submitVideo` 调度 `VideoGenerationWorker` 执行，状态写入 `generations` 表（`type=video`）。
- 前端轮询 `GET /api/videos/{id}/status` 展示进度（PENDING → RUNNING → SUCCEEDED / FAILED）。
- 完成后可预览、下载、复现（参数回填）。

### 2.2 联网搜索

- 对话 / 创作场景下可开启「🌐 联网」，模型通过 Function Calling 调用 `web_search` 工具获取实时信息。
- 后端 `SearchController` + `SearchProvider`（如 Tavily），结果带引用来源卡片。
- 相同 query 在本轮对话内对重复 `web_search` 调用做去重拦截（避免模型重复发起相同查询）。

### 2.3 功能配置开关

- `SearchController` / 视频 / 语音能力均通过配置开关启用/禁用，便于按需开启。

## 3. 接口变更

| 方法 | 路径 | 描述 | 状态 |
|------|------|------|------|
| POST | `/api/videos/generate` | 提交文生视频任务 | ✅ 新增（v1.1.0） |
| GET | `/api/videos/{id}/status` | 查询视频生成状态/结果 | ✅ 新增（v1.1.0） |
| POST | `/api/chat`（扩展 `webSearch`） | 对话启用联网搜索 | ✅ 已交付（依赖对话模块，见 `05` 文档） |
| GET | `/api/search/*` | 联网搜索相关接口 | ✅ 已交付 |
| 配置项 | `agent.features.*` | 语音/视频/搜索开关 | ✅ 新增（v1.1.0） |

> 注：联网搜索的代码实现依附于「语言对话模块」（`AgentOrchestrator` / `ChatController` / `ChatView.vue`），虽随 v1.1.0 交付，但其对话承载链路本身在 [`05` 文档](05-语言对话模块（未来可扩展项）.md) 中仍标注为冻结存档。语音（STT/TTS）链路同属 `05` 文档，本次未交付。

## 5. 已知限制 / 后续计划

- **语音能力（STT/TTS）**：推迟至后续版本，设计见 `05` 文档。
- **对话模块整体**：仍处于冻结存档状态（`05` 文档），对话交互（会话管理、记忆管理、工具调用 UI、对话内文生图、流式对话增强）待主线稳定后恢复。
- 联网搜索依赖对话承载链路，若后续对话模块解冻，其 UI 交互将随对话模式一并回归。
