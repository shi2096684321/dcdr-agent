# 文档索引

按**阅读顺序**排列，而不是按文件名编号 —— 编号是历史累积的结果（例如 `03` 是 V2.0、`04` 是 V1.1），
按编号读会得到倒序的时间线。**文件名不改**：全仓有 140+ 处 `docs/NN-*` 引用（README、代码注释、
技能包），改名会一次性全部失效，收益抵不过风险。

> 惯例：`NN-标题.md` 为正文文档（编号只保证唯一，不保证顺序）；`RELEASE-*.md` 为各版本发布说明；
> `sql/` 手工建库脚本；`design/` 设计稿与设计令牌；`images/` 截图；`eval/` 检索与联网评测。

## 维护约定

1. 新增版本规划 → 文件名顺延（当前到 `23`），并**在本索引第二节按版本插入**，不要只追加到表格末尾。
2. 新增专题文档 → 归到上面对应的类别；若不属于任何一类，再开新分类，而不是塞进"其它"。
3. 发布说明 → 命名严格 `RELEASE-v<版本>.md`，同时更新第三节与本索引。
4. 编号不重排、不回收：已发布的编号即历史，改名会让 140+ 处引用失效。
