## 1. 系统概述

### 1.1 系统定位

本系统是一个基于 Java 技术栈构建的**多模态 AI Agent 应用**，以网页对话为核心交互形式，具备多模型对接、工具调用、记忆管理等 Agent 能力。

### 3.2 分层职责

| 层级 | 职责 | 设计原则 |
|------|------|---------|
| **Controller 层** | 接收 HTTP 请求，参数校验，返回响应 | 不含业务逻辑 |
| **Agent 引擎层** | 编排决策，路由模型，协调工具与记忆 | 系统核心，只依赖接口 |
| **模型抽象层** | 封装不同 AI 服务的调用差异 | 接口统一，实现可插拔 |
| **工具层** | 实现具体工具逻辑 | 独立无状态，可热插拔 |
| **记忆层** | 管理对话历史和上下文 | 按会话隔离 |
| **存储层** | 持久化数据 | 开发期轻量，可切换 |

### 3.3 设计原则

```
1. 单一职责 (SRP)    - 每个类/模块只做一件事
2. 开闭原则 (OCP)    - 加新模型/工具不改旧代码
3. 依赖倒置 (DIP)    - 引擎层依赖接口，不依赖具体实现
4. 配置驱动          - 能配置的不写死
5. 流式优先          - 全程 Reactor 响应式
6. 接口隔离 (ISP)    - Provider 接口按能力细分
```

### 4.3 Agent 引擎层设计 ❄️（语言对话模块，冻结，详见 `05` 文档）

#### 4.3.1 编排器

```java
/**
 * Agent 编排器 - 协调模型路由、工具调用、记忆管理
 */
@Component
public class AgentOrchestrator {
    
    private final ModelRegistry modelRegistry;
    private final ToolRegistry toolRegistry;
    private final ChatMemory memory;
    private final ModelRouter router;
    
    /**
     * 处理用户消息（流式）
     */
    public Flux<ChatChunk> chat(ChatRequest request) {
        return Flux.create(sink -> {
            // 1. 加载会话记忆
            List<Message> history = memory.load(request.getSessionId());
            
            // 2. 路由决策：决定使用哪个模型
            ChatModelProvider provider = router.route(request, history);
            
            // 3. 执行调用（带工具）
            provider.stream(request)
                .doOnNext(chunk -> {
                    sink.next(chunk);
                    // 4. 如果是工具调用结果，可能需要二次调用
                })
                .doOnComplete(() -> {
                    // 5. 保存记忆
                    memory.save(request.getSessionId(), 
                        request.getMessage(), 
                        sink.getAccumulatedResponse());
                })
                .subscribe();
        });
    }
}
```

#### 4.3.2 模型路由器

```java
/**
 * 模型路由器 - 根据消息内容决定使用哪个模型
 */
@Component
public class ModelRouter {
    
    /**
     * 路由决策逻辑：
     * 1. 如果用户指定了模型，直接使用
     * 2. 如果消息包含图片，路由到支持 Vision 的模型
     * 3. 如果消息包含"画/生成图片"关键词，路由到图片模型
     * 4. 默认使用配置的默认对话模型
     */
    public ChatModelProvider route(ChatRequest request, List<Message> history) {
        // 用户显式指定
        if (request.getModel() != null) {
            return modelRegistry.getChatProvider(request.getModel());
        }
        
        // 包含图片 → 需要 Vision 模型
        if (request.hasImages()) {
            return findVisionProvider();
        }
        
        // 默认模型
        return modelRegistry.getDefaultChatProvider();
    }
}
```

### 4.5 记忆层设计 ❄️（语言对话模块，冻结，详见 `05` 文档）

#### 4.5.1 记忆管理

```java
/**
 * 对话记忆接口
 */
public interface ChatMemory {
    
    /** 加载会话历史 */
    List<Message> load(String sessionId);
    
    /** 保存消息（用户消息 + 助手回复） */
    void save(String sessionId, String userMessage, String assistantMessage);
    
    /** 清空会话记忆 */
    void clear(String sessionId);
}
```

#### 4.5.2 上下文窗口控制

```
会话历史消息:
  [System Prompt]                    ← 始终保留
  [User] 你好           [01]          │
  [AI]   你好！         [02]          │  保留最近 N 条
  [User] 今天天气...    [03]          │  (N = maxMemoryMessages)
  [AI]   北京今天...    [04]          │
  [User] 谢谢           [05]          │
  ...                                │
  [User] 最新问题       [20]          │  ← 最新的消息

当消息数 > maxMemoryMessages 时:
  截断最早的消息，保留 System Prompt + 最近 N 条
```

### 8.6 SSE 流式接收

```javascript
// 对话模式的流式接收 (ChatMode)
async function streamChat(message) {
  const response = await fetch('/api/chat/stream', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ sessionId, message, model })
  })
  
  const reader = response.body.getReader()
  const decoder = new TextDecoder()
  
  while (true) {
    const { done, value } = await reader.read()
    if (done) break
    
    const text = decoder.decode(value)
    parseSSE(text, (chunk) => {
      if (chunk.type === 'chunk') appendToMessage(chunk.content)
      else if (chunk.type === 'tool_call') showToolStatus(chunk.tool)
      else if (chunk.type === 'done') finishMessage()
    })
  }
}

// 创作模式的生成请求 (CreativeMode)
// 图片/视频生成使用同步 HTTP + 轮询/长连接，非 SSE
async function generateImage(params) {
  // 1. 显示生成中状态
  creativeStore.isGenerating = true
  
  // 2. POST 请求生成接口
  const response = await fetch('/api/images/generate', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      model: creativeStore.creativeModel,
      prompt: params.prompt,
      referImage: params.referImage,
      size: params.size,
      style: params.style,
      engine: params.engine,
    })
  })
  
  const result = await response.json()
  
  // 3. 将结果添加到历史记录
  if (result.code === 200 && result.data.imageUrl) {
    creativeStore.generatedImages.push(result.data.imageUrl)
    creativeStore.selectedImageIndex = creativeStore.generatedImages.length - 1
  }
  
  creativeStore.isGenerating = false
}
```
